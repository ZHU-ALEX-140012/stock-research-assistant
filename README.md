# 股票投研助手 · 三层合规语义引擎

一个面向个人投研练习的移动端应用 + **三层合规引擎**。前端 Vue3 覆盖选股、个股详情、投研日报、虚拟盘、预警中心、合规实验室等场景；合规校验采用「**前端 L1 硬规则 + L2 语义规则 / 后端 L3 大模型全量判定**」的分层架构，并内置 **L3 降级监控**——大模型不可用时自动降级，保证合规能力不中断。后端为**零第三方依赖**的 Python 标准库服务。

## 核心特性

- **三层合规引擎**
  - **L1 硬规则**：关键词 / 正则级即时拦截（收益承诺、荐股措辞、违禁表述等）。
  - **L2 语义规则**：前端语义规则库，覆盖常见变体与上下文判定。
  - **L3 大模型全量判定**：后端调用大模型做深度合规审查；**缺密钥或调用失败时自动降级**为 L1+L2。
- **L3 降级监控**：实时监测大模型可用性，异常时平滑降级并留痕。
- **虚拟盘**：初始资金统一的模拟交易与统计指标（去绩效化处理）。
- **预警中心 / 投研日报 / 个股详情 / 自选搜索** 等完整投研场景。
- **操作留痕**：关键动作写入合规审计流水，可追溯。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + vue-router 4 + Vite（移动端布局） |
| 合规引擎 | L1/L2 前端 JS（`src/compliance/`），L3 后端 Python |
| 后端 | Python 3 标准库（`http.server` + `threading`），**无第三方依赖** |
| 大模型 | 可选 DeepSeek（OpenAI 兼容），缺密钥自动降级 L1+L2 |

## 快速开始

### 1. 启动后端（L3 合规引擎）

```bash
python compliance_server.py
# 打开 http://127.0.0.1:8792/
```

- 端口可用环境变量覆盖：`PORT=9000 python compliance_server.py`
- 未配置大模型密钥时，后端自动以 L1+L2 规则模式提供合规判定，功能不中断。

### 2. 前端

```bash
cd invest-practice-app
npm install
npm run dev        # 开发模式
# 或
npm run build      # 生产构建，产物在 dist/
```

前端合规接口默认走同源 `/api/compliance/*`；跨域直连时可在 `public/config.js` 里配置 `API_BASE_URL`（例如 `http://127.0.0.1:8792`）。

## 关于大模型（可选）

L3 全量判定依赖大模型；不配置密钥时系统自动降级为前端 L1+L2 规则引擎，仍具备基础合规拦截能力。
